# v0.3.0 release-candidate evidence

This directory contains reproducible local evidence captured before Alex’s final review.

- `desktop-gameplay.png` — desktop gameplay screenshot used in README.
- `375x667-safe.png` — coarse-pointer portrait emulation with top=24px and bottom=20px safe-area overrides.
- `390x740.png`, `390x812.png`, `390x844.png` — requested portrait viewport screenshots.
- `viewport-evidence.json` — raw visualViewport, element bounding-box, scroll, and fit measurements.

All four mobile cases recorded a non-scrollable page and visible board, HUD, and control dock. The evidence represents Chrome device emulation; it complements, not replaces, Bill’s real-phone functional test.
