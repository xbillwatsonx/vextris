# Vextris v0.3.0 release-candidate handoff for Alex

## Scope

Branch: `feat/mobile-touch-controls`
Base: `master`
Publishing status: **local only** — no push, PR, merge, tag, release, or deployment has occurred.

This candidate makes Vextris playable on coarse-pointer portrait phones without a hardware keyboard while preserving desktop keyboard play.

## Review focus

1. Touch behavior: held movement, one-shot actions, cancel/blur cleanup, click fallback, and no duplicate activations.
2. Mobile presentation: state scoping, safe-area layout, fit at four captured portrait viewports, and no desktop regression.
3. Touch initials entry: letter input, backspace, confirm, blank fallback, and overlay behavior.
4. Accessibility: semantic controls, labels, visible focus, `aria-pressed` synchronization, 48px targets, and text-selection suppression.
5. Release artifacts: README screenshots/claims, changelog, CI YAML, templates, and local GitHub drafts.
6. Confirm `vite.config.ts` has no temporary Cloudflare `allowedHosts` setting.

## Known limitations / intentional scope

- Touch layout targets coarse-pointer portrait play; landscape phone UI is not a v0.3.0 goal.
- Explicit buttons were chosen over gesture-only controls for discoverability.
- Screenshot evidence is Chrome emulation, supplemented by manual real-phone testing but not a full browser/device matrix.
- `package.json` remains at `0.2.0`; v0.3.0 bump/tag/release awaits review and approval.
- CI and GitHub templates are committed locally but not yet on GitHub, so there is no remote CI run.
