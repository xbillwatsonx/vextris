2. Use this balance rule

This keeps the game from turning into a rainbow mess.

70% dark foundation

20% purple / blue identity

10% hot accents and gold


That means most of the screen should stay dark, purple should define the game’s personality, and gold / pink / orange should only show up where the player needs to feel energy or importance.

7. Danger state system

This is where the palette becomes reactive.

Normal play

darks + purple + cyan

calm but energized


Elevated pressure

When the board is getting crowded:

boost glow intensity on #B14CFF

add more #FF8C2A to UI accents

make combo / meter edges pulse slightly


Near loss

When the player is close to topping out:

warning text: #FF8C2A

critical pulse: #FF4FD8

board border shifts from #6E2BFF toward #FF4FD8

subtle screen edge pulse in pink-violet


That preserves the Vextris identity while increasing urgency.
